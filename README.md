# Smart Student Management System

## Project Introduction
The Smart Student Management System is a beginner-level C++ console application developed as a university semester project. It helps manage student records, search student information, calculate academic results, and save records for future use.

## Project Objectives
- To understand the practical implementation of C++ programming.
- To manage student records efficiently.
- To practice arrays, loops, conditions, and file handling.
- To calculate student percentages, grades, and pass/fail status.
- To develop problem-solving and programming skills.

## Features
- **Add Student:** Enter student name, roll number, and marks.
- **Display Students:** View all registered student records.
- **Search Student:** Find a student using their roll number.
- **Calculate Result:** Calculate percentage, grade, and pass/fail status.
- **Save Records:** Store student information in a text file.
- **Load Records:** Retrieve previously saved records.
- **Validation:** Prevent duplicate roll numbers and invalid marks.

## Technologies Used
- Programming Language: C++
- IDE: Dev-C++
- Application Type: Console-Based Application
- File Handling: Text File (`student_records.txt`)
- Concepts:
  - Variables and Data Types
  - Conditional Statements
  - Loops
  - Arrays
  - Strings
  - File Handling

## How to Run the Program
1. Download or clone this repository.
2. Open the `.cpp` file in Dev-C++ or another C++ IDE.
3. Compile the program.
4. Run the executable.
5. Follow the on-screen menu to manage student records.
